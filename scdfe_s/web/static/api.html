通信测试 API

scdfe_s 只提供主站与服务端通信测试
通信首页

公共接口

GET /api/health 检查服务；协议接口都支持 status、config、start、stop、logs、alerts、connections 和 points。

主站测试

/api/modbus-tcp/*、/api/modbus-rtu/*、/api/can/* 提供配置、启停、采集和点值更新；CAN 另有 POST /api/can/frame，请求体为 {"arbitration_id":291,"data":"01 02 03"}。

服务端测试

/api/iec104/*、/api/modbus-tcp-server/*、/api/modbus-rtu-server/*、/api/can-server/*、/api/bacnet-server/*、/api/opc-server/* 用于服务端配置和生命周期测试。

IEC104 四遥

POST /api/iec104/update/incremental 请求体为 {"kind":"yc","pnt_no":1,"value":220.5}；POST /api/iec104/update/full 可执行全量更新；POST /api/iec104/commands/{yk|yt}/{pnt_no} 可模拟遥控遥调。

数据库点定义

GET/POST /api/iec104/points 及 PATCH/DELETE /api/iec104/points/{kind}/{pnt_no} 管理 IEC104 测试点。其他协议点通过各自服务的 points 接口管理。使用 S 专库的四遥表和规约辅助表；同号 C 记录不受影响。
