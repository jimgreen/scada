SCADA / API

SCADA 数据访问接口

服务默认读取 D:\codex\scada\db\scada.sqlite3，表结构来自 D:\codex\scada\dbdef\json。写请求使用 UTF-8 JSON，单条响应包含 _version，更新和删除可用 If-Match 做并发保护。

GET/api/schemas

返回全部 23 张表的字段定义、主键、唯一关系和显示元数据。RTU 与通道已经合并到 fes_rtu_define；IEC104、BACnet、OPC、CAN 的四遥地址和报文解析定义分别使用 fes_channel_*_point_define。

GET/api/overview

返回全部表的记录数量；使用 ?rtu_id=7 查看给定 RTU 的关联数量。

GET/api/rtus
POST/api/rtus

RTU 定义增删改查：单条使用 /api/rtus/{rtu_id}，支持 q/limit/offset/sort/order。

GETPATCHDELETE/api/rtus/{rtu_id}

RTU 和通道共用一条记录。新建时必须提供 channel_id 和 channel_type；RTU 表不保存地址和端口。支持 iec104、modbus-rtu、modbus-tcp、can、bacnet、opc、custom。process_enable 是 RTU 自动通信标志：1 才由 scdfe_c 自动启动并守护，0 时完全跳过并可人工 --rtu-id 调试。状态、线程 ID、时间、心跳、退出码和错误字段由 scdfe_c 回写；异常通信线程会自动恢复，但不保存恢复次数或恢复时间。

GETPOSTPATCH/api/rtus/{rtu_id}/channel

独立维护 RTU 的通道字段 channel_id、channel_type。一个 RTU 只能有一个通道；POST 只用于尚未配置通道的记录，已有通道使用 PATCH。连接地址、端口、串口或节点由对应协议参数表维护。

GETPOSTPATCHDELETE/api/rtus/{rtu_id}/channel/parameters

管理该 RTU 的个性化通道参数。参数表按类型选择 fes_channel_iec104_define、fes_channel_modbus_rtu_define、fes_channel_modbus_tcp_define、fes_channel_can_define、fes_channel_bacnet_define 或 fes_channel_opc_define；IEC104、BACnet、OPC 的内部 id 由 POST 自动分配，rtu_id 由路径确定。

GET
POST/api/rtus/{rtu_id}/points/{yc|yx|yt|yk}

按 RTU 作用域管理四遥数据；单条使用末尾点号，例如 /api/rtus/7/points/yc/12。

POST/api/rtus/{rtu_id}/commands/{yk|yt}/{pnt_no}

由 WEB 下发遥控或遥调。请求体只接受 {"value":1} 或 {"value":55.5}，必须携带当前记录的 If-Match 版本号。服务端检查闭锁、待处理指令、遥调工程上下限和协议能力后，把递增的 cmd_time 写入点表；返回 202 表示已进入通信线程队列，实际设备确认仍由对应规约主站完成。CAN 和 custom 当前没有统一的四遥点下发映射，返回 409。

GET
POST/api/points/{yc|yx|yt|yk}

跨 RTU 查询或新增四遥记录；也可使用 /api/tables/{table}/rows 操作所有辅助定义表。

PATCH
DELETE/api/rtus/{id} /api/rtus/{id}/points/{kind}/{pnt_no}

PATCH 只提交需要修改的字段；主键不可修改。删除 RTU 前必须先删除其协议参数和四遥记录。

GET/api/processes
POST/api/processes/control

进程监控接口。GET 返回主进程、数据库写进程和已登记调试进程的真实 PID/父 PID、状态、启停时间、心跳、错误、日志进程名及当前异步操作步骤。POST 请求体为 {"target":"main|writer|debug:7|all","action":"start|stop|configure"}；调试任务可附 include_in_all。控制操作按依赖顺序执行，写库停止会先暂停通信并排空队列；接口返回 202，随后轮询 GET 查看 operation.status/stage/steps。运行进程表不允许通过泛型表接口直接修改。

GET/api/scdfe_c/status
PATCH/api/scdfe_c/control

查询或控制 scdfe_c 主进程。状态查询支持 limit（默认 50，最多 500）、offset、q、process_status、process_enable；响应包含分页总数和全库线程统计 counts。通信线程异常会自动恢复，但不保存重启次数或重启时间。同一服务器仅允许一个自动守护实例，不同 RTU 的人工调试可并行，同一 RTU 仅允许一个通信所有者，互斥不受数据库路径影响。启动时检测到另一自动守护实例会返回 HTTP 409（process_already_running），不修改本库控制配置。控制字段包括 process_enable、运行周期、log_retention_hours（日志保留小时数，1–87600）和 worker_start_delay_ms（通信线程顺序启动间隔，默认 250 ms）；修改采集周期、失败重试周期或日志目录会在下一次扫描中平滑重载通信线程。响应中的 item.process_pid 是主进程 PID，rtus[].thread_id 是对应通信线程的 native ID；状态、时间、心跳、退出码和错误由进程回写，线程停止时 thread_id 为 0。

GET/api/scdfe_c/logs[?process=...&rtu_id=...]
GET/api/scdfe_c/logs/{filename}?tail=200

按进程/RTU列出小时日志或读取尾部。通信文件位于 YYYY/MM/DD/HH/scdfe_c-rtu-7-YYYYMMDD-HH.log，不含通道号；正文时间为本地 HH:MM:SS，日期和小时来自路径及文件名，不含年月日、毫秒或时区。

GET/api/scdfe_c/logs/search

组合检索日志正文和文件：q 为关键词，level=INFO|WARNING|ERROR|PROCESS 为日志类型，start/end 为带时区的 ISO 8601 起止时间，process、rtu_id、file_query 为进程/RTU/文件名条件；filename 限定当前文件，可包含 YYYY/MM/DD/HH/ 相对路径；省略则检索全部匹配文件。limit 为每批 1–5000 条，返回 items、next_cursor、has_more 和扫描统计；带游标继续检索更早的小时日志。后端每次最多扫描 4 MB，单行最多 128 KB，避免日志筛选无限占用内存。

GETPATCHPOST/api/modbus-tcp/* /api/modbus-rtu/* /api/can/*

三个独立测试页面的统一接口：status/config/start/stop/logs/alerts/connections/points，以及 update/incremental、update/full、commands/{yk|yt}/{pnt_no}。Modbus-TCP 和 Modbus-RTU 的配置可选择 master 主站或 server 从站模式；CAN 是总线主站/测试端，没有独立的通用服务器角色。

POST/api/modbus-tcp/poll /api/modbus-rtu/poll /api/can/poll

执行一次主站采集并返回适配器结果。CAN 还提供 POST /api/can/frame，请求体示例 {"arbitration_id":291,"data":"01 02 03"}。

GETPOST/api/iec104/status /start /stop

查看 IEC104 测试从站状态，或通过 Web 启动/停止监听服务。启动时按配置读取选定 RTU 的通道参数、四遥定义和 IEC104 点映射。

GETPATCH/api/iec104/config

读取或修改监听地址、端口、RTU 编号、周期、选择执行超时和最大连接数。服务运行时修改会自动停止并按新配置重载。

GETPOST/api/iec104/points /api/iec104/points/{kind}/{pnt_no}

查看或新增四遥点定义，并通过单点路径 PATCH/DELETE 修改或删除。点表仍写入现有四遥定义表，服务重载后生效。

POST/api/iec104/update/incremental

增量更新一个点，体例：{"kind":"yc","pnt_no":1,"value":220.5}。遥信/遥测有客户端连接时按自发传送原因主动上送。

POST/api/iec104/update/full

执行全遥更新并分批主动发送遥信、遥测。可传 {"values":{"yc":{"1":220.5},"yx":{"1":true}}}。

POST/api/iec104/commands/{yk|yt}/{pnt_no}

Web 测试用遥控/遥调接口，修改站内命令点并记录日志。真实客户端遥控/遥调由 c104 回调接收并记录。

GET/api/iec104/connections /logs /alerts /commands

查看客户端接入、APDU 调试日志、启动/更新告警和最近收到的遥控/遥调命令。

POST /api/rtus
Content-Type: application/json

{"rtu_id":7,"channel_id":70,"channel_type":"modbus-tcp","code":"station-7","name":"示例站"}

POST /api/rtus/7/points/yc
{"pnt_no":12,"code":"U_A","name":"A相电压","value":220.5,"status":0}

泛型单条路径为 /api/tables/{table}/rows/{key}，联合主键按表结构顺序用逗号拼接。跨 RTU 点表的单条路径为 /api/points/yc/7,12；指定 RTU 路径只接受点号，不接受另一个 RTU 的复合键。旧的 /api/channels 接口和旧协议表名已删除。

集合支持 q、limit（1–500，默认 25）、offset、sort、order、fields（逗号分隔的字段投影）和字段等值过滤（例如 rtu_id=7）。指定 fields 时主键与 _version 自动返回；详情接口仍返回完整记录。PATCH 支持传 null 清空数值字段，传空字符串清空文本。超出 JavaScript 安全整数范围的 KEYID 等整数以十进制字符串传输。

400 表示参数或字段无效，404 表示记录不存在，409 表示重复主键、版本冲突、仍有关联数据、测点闭锁、已有待处理指令、指令范围错误或服务器自动守护实例已被占用；428 表示缺少 If-Match。普通 PATCH 只编辑数据库定义，专用 command POST 才会进入现场下发队列。
