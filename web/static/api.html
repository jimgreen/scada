SCADA / API

SCADA 数据访问接口

服务默认读取 D:\codex\scada\db\scada.sqlite3，表结构来自 D:\codex\scada\dbdef\json。写请求使用 UTF-8 JSON，单条响应包含 _version，更新和删除可用 If-Match 做并发保护。

GET/api/schemas

返回全部 18 张表的字段定义、主键、唯一关系和显示元数据。RTU 与通道已经合并到 fes_rtu_define，fes_scdfe_c_define 保存主进程控制记录。

GET/api/overview

返回全部表的记录数量；使用 ?rtu_id=7 查看给定 RTU 的关联数量。

GET/api/rtus
POST/api/rtus

RTU 定义增删改查：单条使用 /api/rtus/{rtu_id}，支持 q/limit/offset/sort/order。

GETPATCHDELETE/api/rtus/{rtu_id}

RTU 和通道共用一条记录。新建时必须提供 channel_id 和 channel_type；字段还包括 chan_addr、chan_port、status。支持 iec104、modbus-rtu、modbus-tcp、can、bacnet、opc、custom。process_enable 控制通信线程启停，process_restart=1 请求一次重启；process_status、process_pid（通信线程 ID）、时间、心跳、退出码和错误字段由 scdfe_c 回写。

GETPOSTPATCHDELETE/api/rtus/{rtu_id}/channel/parameters

管理该 RTU 的个性化通道参数。参数表按类型选择 fes_channel_iec104_define、fes_channel_modbus_rtu_define、fes_channel_modbus_tcp_define、fes_channel_can_define、fes_channel_bacnet_define 或 fes_channel_opc_define。

GET
POST/api/rtus/{rtu_id}/points/{yc|yx|yt|yk}

按 RTU 作用域管理四遥数据；单条使用末尾点号，例如 /api/rtus/7/points/yc/12。

GET
POST/api/points/{yc|yx|yt|yk}

跨 RTU 查询或新增四遥记录；也可使用 /api/tables/{table}/rows 操作所有辅助定义表。

PATCH
DELETE/api/rtus/{id} /api/rtus/{id}/points/{kind}/{pnt_no}

PATCH 只提交需要修改的字段；主键不可修改。删除 RTU 前必须先删除其协议参数和四遥记录。

GET/api/scdfe_c/status
PATCH/api/scdfe_c/control

查询或控制 scdfe_c 主进程。控制字段包括 process_enable、process_restart、运行周期、log_retention_hours（日志保留小时数，1–87600）和 worker_start_delay_ms（通信线程顺序启动间隔，默认 250 ms）；修改采集周期、失败重试周期或日志目录会在下一次扫描中平滑重载通信线程。响应中的 item.process_pid 是主进程 PID，rtus[].thread_id 是对应通信线程的 native ID；状态、时间、心跳、退出码和错误由进程回写，线程停止时 thread_id 为 0。

GET/api/scdfe_c/logs[?process=...&rtu_id=...&channel_id=...]
GET/api/scdfe_c/logs/{filename}?tail=200

列出主进程、通信线程或数据库写进程的按小时日志文件，或安全读取日志尾部。文件名不能包含路径分隔符，单次读取最多 5000 行；日志级别写在行内容中，不再按 normal/alarm/error/process 拆文件。

POST /api/rtus
Content-Type: application/json

{"rtu_id":7,"channel_id":70,"channel_type":"modbus-tcp","chan_addr":"127.0.0.1","chan_port":502,"code":"station-7","name":"示例站"}

POST /api/rtus/7/points/yc
{"pnt_no":12,"code":"U_A","name":"A相电压","value":220.5,"status":0}

泛型单条路径为 /api/tables/{table}/rows/{key}，联合主键按表结构顺序用逗号拼接。跨 RTU 点表的单条路径为 /api/points/yc/7,12；指定 RTU 路径只接受点号，不接受另一个 RTU 的复合键。旧的 /api/channels 接口和旧协议表名已删除。

集合支持 q、limit（1–500，默认 25）、offset、sort、order 和字段等值过滤（例如 rtu_id=7）。PATCH 支持传 null 清空数值字段，传空字符串清空文本。超出 JavaScript 安全整数范围的 KEYID 等整数以十进制字符串传输。

400 表示参数或字段无效，404 表示记录不存在，409 表示重复主键、版本冲突或仍有关联数据。所有四遥写入均为数据库记录编辑，不下发现场设备命令。
