SCADA / scdfe_c

RTU 与四遥数据 API

本页面用于 RTU、通道、四遥定义、协议辅助表、进程监控和运行日志维护。服务端/主站通信测试请打开独立的 scdfe_s 通信测试服务。

GET/api/rtus
POST/api/rtus

查询或新建 RTU；单条 RTU 使用 /api/rtus/{rtu_id}。

GETPATCH/api/rtus/{rtu_id}/channel

维护一个 RTU 对应的通道和协议类型；参数位于 /api/rtus/{rtu_id}/channel/parameters。

GETPOSTPATCHDELETE/api/rtus/{rtu_id}/points/{yc|yx|yk|yt}

维护 RTU 作用域下的四遥定义；遥控遥调仍通过 /api/rtus/{rtu_id}/commands/{yk|yt}/{pnt_no} 下发。

GET/api/processes
POST/api/processes/control

查询和控制主进程、数据库写进程及调试进程。

GET/api/scdfe_c/status
PATCH/api/scdfe_c/control

控制 scdfe_c 守护进程和通信线程；日志接口为 /api/scdfe_c/logs。

GETPATCH/api/scdfe_c/command-server

维护 TCP 指令服务监听地址、端口、认证令牌和日志保留小时数。进程在“进程监控”中单独启停，运行时不可修改监听配置。

{"request_id":"req-001","op":"command","rtu_id":7,"kind":"yk","point_no":3,"value":1,"token":"..."}

TCP 服务按行接收 UTF-8 JSON，支持 yk/yt；每个 request_id 只提交一次，成功响应为 command_status=pending，随后由 scdfe_c 通信线程下发。
