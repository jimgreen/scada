SCADA / scdfe_c

通道、RTU 与四遥数据 API

通道先定义，RTU 再绑定。通道由 (channel_type, channel_id) 复合确定：服务端先选择对应的协议通道表，再按 channel_id 查询。

GET POST PATCH DELETE /api/channels
GET PATCH DELETE /api/channels/{channel_type}/{channel_id}

通道目录支持分页、搜索、排序和字段投影；新建通道时会写入对应的 IEC104、Modbus、CAN、BACnet 或 OPC 通道定义表。协议参数入口为 /api/channels/{channel_type}/{channel_id}/parameters。

GET POST /api/rtus
GET PATCH DELETE /api/rtus/{rtu_id}

查询、创建和维护 RTU。创建 RTU 时提交 channel_type 与 channel_id，服务端按复合键校验通道绑定。

GET POST PATCH DELETE /api/rtus/{rtu_id}/points/{yc|yx|yk|yt}

维护 RTU 作用域下的四遥定义；遥控遥调仍通过 /api/rtus/{rtu_id}/commands/{yk|yt}/{pnt_no} 下发。

GET POST /api/processes
POST /api/processes/control

查询和控制主进程、数据库写进程及调试进程。

GET PATCH /api/scdfe_c/status
PATCH /api/scdfe_c/control

控制 scdfe_c 守护进程和通信线程；日志接口为 /api/scdfe_c/logs。

GET PATCH /api/scdfe_c/command-server

维护 TCP 指令服务监听地址、端口、认证令牌和日志保留小时数。
