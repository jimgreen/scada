SCADA WEB 通信规约配置使用说明

通过“数据与定义”页面维护 RTU、通道、四遥点和协议辅助表。本文覆盖 IEC104、Modbus-TCP、Modbus-RTU、CAN、OPC UA、BACnet 六类通信需求。

一、页面总览

  1. 启动 Web 服务后打开 http://127.0.0.1:8877/。在左侧进入“数据与定义”。
  2. 顶部 RTU 选择器决定当前四遥、协议参数和辅助表的作用范围；每个 RTU 保持一 RTU 一通道关系。
  3. 分页标签包含“RTU 与通道、遥测、遥信、遥调、遥控、协议参数、辅助表”。协议参数和辅助表标签会根据当前通道类型显示。
  4. 列表中的“常用字段、四遥数据、全部字段”用于切换查看；“表结构”可查看字段类型和允许范围。
修改已保存到 SQLite 后，通信线程会按 RTU/通道定义重新加载。正在运行的连接可能在下一个扫描周期应用新参数。

二、通用新增、修改、删除

新增 RTU 与通道

  1. 点击“新建 RTU”。
  2. 填写 rtu_id、名称、channel_id 和 channel_type。
  3. 保存 RTU 后，点击“通道参数”新增对应规约参数。

修改

  1. 在 RTU 与通道页点击“编辑”，或进入相应分页标签。
  2. 修改协议参数、四遥定义或辅助表字段。
  3. 点击保存；主键和所属 RTU 由页面保护，不能在编辑中改动。

删除

  1. 删除 RTU 前，页面先读取删除预览。
  2. 确认框列出通道、协议参数、辅助表和四遥表的实际记录数量。
  3. 确认后在一个事务中级联删除，失败则整体回滚。

新增、修改、删除遥测、遥信、遥调、遥控的步骤相同：选择 RTU → 进入对应标签 → 点击“新增记录”或行内“编辑/删除”。遥控和遥调还可在行内填写值并点击“下发”。

删除提示：删除 RTU 会同步删除该 RTU 的通道记录、协议参数、协议辅助表、点映射表、遥测、遥信、遥调、遥控及遥调遥控下发信息，操作不可恢复。请核对预览中的数量后再确认。

三、IEC104

将 RTU 的通道类型设置为 iec104，在“协议参数”中维护 fes_channel_iec104_define，在“辅助表”中维护 fes_channel_iec104_point_define。

通道参数

remote_host、remote_port、rtu_addr、ycbegin_addr、yxbegin_addr、ykbegin_addr、ytbegin_addr、yc_data_type、yx_data_type、yk_excute_type、yt_excute_type、call_alldata_time、if_autosend_alldata。

点映射

每行用 kind（yc/yx/yt/yk）和 pnt_no 对应四遥点，填写 io_address、type_id、report_ms、command_mode、qualifier；有联动需求时填写 related_io_address 与 related_io_autoreturn。

操作

  1. 新增 RTU，选择 IEC104，保存通道参数。
  2. 在辅助表新增每个点的 IOA 与类型映射。
  3. 修改时只改参数或映射字段并保存；删除行后该点不再解析或下发。

四、Modbus-TCP

通道类型选择 modbus-tcp，参数表为 fes_channel_modbus_tcp_define。

连接参数

remote_host、remote_port、unit_id、connect_timeout、response_timeout、retry_count、keep_alive。

辅助表

fes_channel_modbus_define 定义通道召唤范围；fes_channel_modbus_define_call 定义召唤顺序；fes_channel_modbus_define_data 定义寄存器、位域、字节序和工程换算；fes_channel_modbus_define_ytyk 定义遥调/遥控写入。

召唤功能码使用 1/2/3/4。线圈和离散量单帧最多 2000 点，寄存器单帧最多 125 个。地址、点类型、trans_type、位偏移、字节序和遥调遥控寄存器都在辅助表中维护。

操作

  1. 新增 RTU 并选择 Modbus-TCP。
  2. 填写网络参数，再按报文组织建立召唤、数据和遥调遥控行。
  3. 修改或删除辅助行后，通信线程按新的轮询计划解析数据。

五、Modbus-RTU

通道类型选择 modbus-rtu，参数表为 fes_channel_modbus_rtu_define；召唤、数据和遥调遥控辅助表与 Modbus-TCP 共用。

串口参数

serial_port、baudrate、bytesize、parity、stopbits、unit_id、response_timeout、retry_count。bytesize 固定为 8，parity 使用 N/E/O，stopbits 使用 1 或 2。

操作

  1. 新增 RTU，选择 Modbus-RTU 并填写串口参数。
  2. 在“辅助表”中配置功能码、起始地址、数量、位域和字节序。
  3. 在遥调遥控定义中配置写寄存器或线圈；保存后按新定义通信。

六、CAN

通道类型选择 can。参数表为 fes_channel_can_define，报文解析表为 fes_channel_can_point_define。

通道参数

interface、channel、bitrate、data_bitrate、fd、receive_own_messages、receive_timeout、retry_count、is_extended_id。

报文解析

按 kind、pnt_no 维护 frame_id、tx_frame_id、response_id、扩展帧/FD 标志、字节和位偏移、位宽、value_type、byte_order、scale、offset、质量码位置与掩码，以及控制报文十六进制数据。

操作

  1. 新增或修改 CAN 通道参数。
  2. 为每个四遥点新增解析映射，核对帧 ID、位域和字节序。
  3. 删除映射即可停止该点的接收解析或发送。

七、OPC UA

通道类型选择 opc。参数表为 fes_channel_opc_define，点映射表为 fes_channel_opc_point_define。

连接与点

维护 opc_interval、opc_user、opc_pwd、opc_domain、opc_name。点行维护 kind、pnt_no、node_id、data_type、value_attribute、quality_attribute、deadband。

使用 OPC UA 地址和明确的 NodeId；修改 NodeId 后保存，通信线程会使用新节点。对象类型不使用旧 OPC DA/COM 别名。

八、BACnet

通道类型选择 bacnet。参数表为 fes_channel_bacnet_define，点映射表为 fes_channel_bacnet_point_define。

连接与对象

维护 bind_ip、bind_port、dev_id、remote_host、remote_port。点行维护 kind、pnt_no、object_type、instance、property_identifier、quality_property、priority、array_index。

object_type + instance 是对象地址；常用属性是 presentValue 和 statusFlags。新增、编辑、删除步骤与其他协议相同，保存后由后台重新加载对象映射。

九、常见问题

现象处理
RTU 下拉框显示不全点击刷新，页面会重新读取 RTU 列表；顶部选择器用于所有分页。
协议参数不存在先在“协议参数”标签新增当前通道类型的参数记录。
通道类型切换提示冲突先删除旧协议参数和不再使用的辅助记录，再保存新的通道类型。
保存失败查看表结构中的字段类型、允许范围和必填字段；寄存器数量、串口参数等有协议限制。
删除 RTU 前提示数量核对预览中的表名和记录数。取消确认不会删除任何数据，确认后所有记录在一个事务中处理。
通信未立即使用新定义检查通信监控和运行日志；后台线程会在重新加载或下一个扫描周期应用配置。
文档与当前 SCADA WEB schema/API 保持同步；字段以页面“表结构”和当前数据库定义为准。
