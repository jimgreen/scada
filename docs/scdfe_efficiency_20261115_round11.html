功能与正确性

修复刷新时间为 NULL 的遥测/遥信点值或质量变化后不更新时间的问题；自动刷新时间只维护一次变化索引。T 根据变化比例选择变化点或整组读取，保持删除、空值、映射边界及失败重试语义。SOE 不使用最新值合并。

C/S/T 新增“指令追踪”：入库、派发、IEC104 选择/确认、执行请求及结果阶段持久化；C/T 共用记录，S 保存接收记录。同一毫秒多个 S 接收指令独立保留。派发状态在设备 I/O 前提交，未知结果不自动重发；已确认但点表结果丢失时恢复状态，避免重复执行。驱动明确返回 False 按失败处理。

IEC104 激活确认、Modbus 响应和驱动调用完成均不代表设备实际动作完成。当前未关联回采点，页面明确显示“未关联回采验证”。S 选择/撤销查业务日志；升级前历史不补造，指令表暂不自动清理；不确定命令需人工核对，未提供自动重发。

接口 GET /api/command-traces 支持 RTU/点/阶段过滤与命令编号游标分页。最新页 5 秒刷新，隐藏与历史页暂停，单请求防重叠，未变化行保留 DOM，错误保留已有数据。

SOE 慢连接隔离

真实 TCP 同时连接正常客户端和不发送确认的客户端，预置 384 条事件，128 条一批，受控 5 ms 泵送。在 2 秒观察窗内，旧版正常客户端只收到 128 条后等待慢端；新版正常客户端收到全部 384 条，完成时间 27.774 ms，顺序正确。两版持久化游标均保留为 0，未跳过慢端未确认事件。

额外回归覆盖慢端断线、新连接补发全部缺口；逐条核对状态、质量、CP56 字节，正常存活连接不重复补发该缺口。运行诊断显示各连接进度，日志记录连接与对端。数据库保存保守共享确认下限，各活动连接独立推进；重启或重连可能重复投递，不承诺恰好一次。
