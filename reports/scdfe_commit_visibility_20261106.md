# SCDFE 数据库、通信与日志交互验收（2026-11-06）

三套 Web 已用修改后的代码在原端口运行。最终完整回归 **456 项：455 通过、1 跳过、0 失败，耗时 247.702 秒**。跳过的是 Windows 账户没有权限创建符号链接的一项测试。本轮使用项目的 Windows 环境、SQLite 和本机协议对端；未接现场设备。

## 本轮改动

| 范围 | 修复与验证 |
|---|---|
| C 数据库写入 | 遥测、遥信、遥控、遥调点的批量修改不再先逐条读取整行。修改按主键和可选版本号执行；仍保留缺行 404、版本冲突 409 和整批回滚。其他有跨字段约束的表保留原校验。没有改表或迁移数据。 |
| S 的 IEC104 服务 | Web 增量修改、全量上送和模拟命令先验证并提交点值，再更新规约站。注入数据库写失败，已连接客户端再次总召仍读到旧值；整批含未知点时已验证的点也不改变。若提交成功后上送失败，接口明确告知数据已经写入；短浮点存储与线上精度一致。 |
| T 通道与命令 | 区分 IEC104 公共地址（1–65534）和 Modbus 单元地址（1–247），拒绝通过通道创建接口写入 PID 等运行字段。C 端已经确认的命令不会因 T 本地日志落盘出错而返回否定确认。 |
| 三套日志与 Web | 运行日志及报文说明中的换行不能把正文伪装成另一条报文；HEX 数据仍保留。S/T 目录枚举复用文件属性，目录无变化时也不重建页面按钮。三套页面跟随当前进程的最新小时；浏览历史文件时可保持选择，复制回来的旧文件不会因为修改时间较新而被误选。 |

- 通过三套 Web 的链接实际读取 24 个 HTML 页面，连同脚本、样式共 47 个资源（C/S/T 各 5/27/15 个），全部返回 HTTP 200。用浏览器实际打开三个站点并操作日志页。隔离日志夹具验证三套页面在本进程 01 时滚动到 02 时，不跳去另一个进程的 03 时文件；S/T 手选历史小时后停止跟随。
- 原端口 T 通道 1：本机 IEC104 客户端保持同一条连接，收到周期上送，并总召读到遥测 **42**。默认关闭报文保存时文件计数不变；仅对通道 1 开启后，RX 从 19 增至 20，TX 从 57 增至 63；再次关闭后计数不再增加。浏览器按“报文 / RX”和“报文 / TX”都找到了本次记录。随后撤销通道覆盖，三套系统恢复全局关闭、各通道继承的状态。
