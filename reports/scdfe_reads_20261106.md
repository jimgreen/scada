## 真实链路与回归

两轮均使用独立临时库和环回 TCP：S Modbus 源站、C 两个采集通道、T 两个 Modbus TCP 和两个 IEC 104 转发通道。持续测试里逐轮读回源端、采集值及质量码和四个外部协议客户端；反向控制从 T 写入后验证源端寄存器/线圈。并发监测启用与关闭报文保存的通道，分别验证 RX/TX 和进程心跳。每轮结束验证两个数据库的 SQLite 完整性及外键。

最终版本另有约 75 秒的独立并发读者：1,810 次 S 协议读取、1,055 次 SQLite 读取、179 次 T 新连接读取、49 轮日志分页抽查（294 条与原文件对照），均通过。两轮均已清理临时服务。

完整回归运行 480 项、耗时 239.419 秒：479 通过，0 失败；唯一跳过项是 Windows 无创建符号链接权限（WinError 1314）。[完整回归输出](scdfe_reads_20261106/full_regression.txt) · [8 分钟结果](scdfe_reads_20261106/acquisition_logs_ui.json) · [最终 3 分钟结果](scdfe_reads_20261106/including_ownership.json)。

## 原端口

回归通过后仅重启三个 Web。8877 / 8878 / 8879 各发起 48 个同步健康请求，全部成功，P95 为 18.76 / 17.32 / 21.29 ms。对每个端口选取同一份已有日志取最新 3 条：C 65,536 → 4,096 字节，S 65,536 → 4,096 字节，T 16,761 → 4,096 字节；三组结果的 SHA-256 与重启前一致。

浏览器核对 C 的 RTU 切换、S 的刷新及编辑器、T 的通道 RX/TX 筛选，未观察到页面异常。在 S 四遥页面实际取得 63 个厂站候选与 RTU 2 的 100 个遥测点，点 1 的显示及编辑字段和完整 API 记录一致；通道页面的状态开关仍可用。没有为此修改原库业务记录。

T 通道 1 原进程 PID 17736 与 2404 监听保持不变。真实 IEC 104 总召返回遥测 42.0、遥信 false、质量码均为 0，与数据库相符。原库与本轮测试前在线备份对照：表结构和 28 张表的业务数据相同（排除 T 心跳等运行元数据），完整性正常，无外键错误。
