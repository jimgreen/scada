# 删除设备值字段后的原始值/工程值测试（2026-11-01）

本轮在 `D:\codex\scada` 完成物理数据库、schema、数据类、采集写回、Web 和测试的同步变更。YC/YX 各删除 12 个设备值/状态/时间字段，不提供旧字段访问。遥测原始值来自通信采样，工程值为 `raw_base + raw_scale * raw_value`。测试配置基值 2、比例 1.1。

## 数据核验

正式库保留 61 个 RTU（60 个协议测试站及 1 条已有 RTU），每个测试站 YC1000/YX1000/YK200/YT200。遥测 60000 行：60000 个不同原始值、60000 个不同工程值、两值相等 0 行、换算错误 0 行；遥调 12000 行同样通过核验。遥信 60000 行、遥控 12000 行保留。遥测/遥信质量码随机分布于 0–3，允许不同点使用相同质量码；每点原始质量与工程状态保持一致。

删除列前后以 SHA-256 核验所有保留字段相同，再重置明确标记的测试值。SQLite 完整性为 `ok`、外键违规 0；备份与逐点抽样见 [迁移报告](remove_device_values_20261101.json)、[数据核验](raw_engineering_values_20261101.json)。

## 性能测量口径

同一 Windows/Python/SQLite 环境，每站 1000 YC + 1000 YX，每站 20 周期，每规模每版本各 3 次，串行执行、每轮交换版本顺序。模拟样本按 RTU 独立固定种子生成，每个 YC 原始值均不同并每周期变化，工程值按比例换算；每个 YC/YX 质量每周期从其他三个码中随机选择，YX 仍为二值。

计时覆盖样本生成、工程换算、通信线程、真实 spawn 写库进程、IPC、事务提交及队列排空；不计数据库初始化，不包含现场网络、串口或 CAN 设备时延。

对照基线由当前源码只展开 YC 质量/时间绑定参数生成：同一 schema、同一字段、同一原始/工程值和写库算法，独立绑定参数与共享绑定参数对照。此基线不是旧 Git 版本；生成规则在 `unshared_binding_source()`，拒绝不匹配的源码模式。两份冻结源码、随机输入和基准工具哈希见 JSON。不能把这里的收益解释为完整旧版本升级收益。
